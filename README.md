## Real RAG Demo

From the project root, activate the virtual environment:

```powershell
.\.venv\Scripts\Activate.ps1
```

Copy `backend/.env.example` to `backend/.env` and set your local Gemini API
key. Start FastAPI from the project root:

```powershell
python -m uvicorn backend.app.main:app --reload
```

At startup, the application indexes `documents/leave_policy.txt` into the
persistent local ChromaDB store through the existing ingestion pipeline. It
does not re-index the sample document on every API request.

Open Swagger at [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) and
try `POST /api/rag/ask` with:

```json
{
  "question": "How many annual leave days are employees entitled to?"
}
```

The answer is generated by Gemini from the document context retrieved from
`leave_policy.txt` through the RAG pipeline.
